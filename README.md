# youtube-thumbnail-tool

초보 운영자를 위한 빠른 안내서입니다. 이 문서는 **Codex(설계/수정)**와 **PowerShell(실행/생산)**의 역할을 분리해서 설명하고, 폴더 구조/재실행 순서를 쉽게 따라할 수 있도록 정리했습니다.

## 1) 역할 분리: Codex vs PowerShell

### Codex (설계/수정 담당)
- **무엇을 하는가:** 작업 흐름 설계, 프롬프트/템플릿 수정, 파일 구조/규칙 정의.
- **언제 쓰는가:**
  - 썸네일 디자인 규칙을 바꾸고 싶을 때
  - 입력/출력 폴더 구조를 바꾸고 싶을 때
  - 실행 스크립트(예: `.ps1`)의 로직을 수정해야 할 때
- **주의:** Codex는 설계/수정 제안이 목적이며, **실행은 PowerShell에서** 해야 합니다.

### PowerShell (실행/생산 담당)
- **무엇을 하는가:** 실제 생성 작업 실행, 로그 확인, 결과물 확인.
- **언제 쓰는가:**
  - 썸네일을 실제로 생성해야 할 때
  - 폴더 준비/정리, 배치 실행, 재실행을 해야 할 때
- **주의:** 스크립트 실행은 항상 PowerShell에서 진행합니다.

> 요약: **Codex는 설계/수정, PowerShell은 실행/생산**입니다.

## 2) 폴더 구조와 사용법

```
input/
  background/
output/
```

### `input/background` 폴더
- **의미:** 썸네일 배경 이미지(또는 배경 후보)를 넣는 곳입니다.
- **사용법 예시:**
  1. 배경 이미지 파일을 준비합니다.
     - 예: `input/background/game01.jpg`
     - 예: `input/background/interview_blue.png`
  2. 실행 스크립트가 이 폴더에서 배경을 읽어 썸네일을 만듭니다.

> 팁: 배경 이미지 이름을 이해하기 쉬운 이름으로 지정하면 작업 관리가 쉬워집니다.

### `output` 폴더
- **의미:** 생성된 썸네일 결과물이 저장되는 곳입니다.
- **여러 장이 생성되는 이유:**
  - 썸네일은 **A/B 테스트**를 위해 여러 버전을 만듭니다.
  - 예: 제목 텍스트 위치/색상/크기만 조금씩 바꿔 여러 장을 생성하여 성과 비교

## 3) CMD/PowerShell 창을 닫았다가 다시 시작할 때의 정확한 순서

1. **작업 폴더로 이동**
   - PowerShell을 열고 프로젝트 폴더로 이동합니다.
   - 예: `cd C:\path\to\youtube-thumbnail-tool`

2. **입력 폴더 준비 확인**
   - `input/background` 폴더에 배경 이미지가 있는지 확인합니다.

3. **실행 스크립트 실행**
   - 프로젝트에서 사용하는 스크립트(예: `run.ps1`)를 실행합니다.
   - 예: `./run.ps1`

4. **`output` 확인**
   - `output` 폴더에 새 결과물이 생성되었는지 확인합니다.

> 재시작 요약: **폴더 이동 → 입력 확인 → 스크립트 실행 → 출력 확인**
